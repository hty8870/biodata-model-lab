# 数据、标签与评测：怎样避免把分数变化误读为模型进步

## 证据层次

| 来源 | 可以说明什么 | 不可以冒称什么 |
|---|---|---|
| 有限集合／有限槽位程序oracle | 在题定形式语义下可精确复算 | 任意自然语言解释正确、真人需求已覆盖 |
| 模板和AI作者文本＋构造继承标签 | 学生对受控代理任务的符合度 | 独立自然用户分布 |
| 多模型共识、独立AI盲复核 | 判断一致性、可追溯争议和裁决 | 人工金标、标签绝无共同盲点 |
| 公开基准的人工参考 | 相应NLI／启发式／合同子能力 | 记忆编辑权限、持久化或生产安全 |
| 真实使用反馈 | 在合适设计下研究用户效用 | 本仓没有提供这类效果试验，不能用合成分数代替 |

LLM别名、接口回显与真正的服务权重不是同一层认证。资料保留请求名、可得回显、解码参数和角色；历史没有记录的字段不补造。本地教师标签`batiai/qwen3.8-27b:iq3`曾回报qwen35家族，但未独立认证底座版本；不得据标签名认定官方模型身份。

数据文件保留原ID、分区、标签来源和审计信息，便于复算；**它们不应一并进入模型或LLM提示**。源编号、作者、gold后缀、teacher votes和期望行为都可能成为捷径。R2/LLM原批曾携带与gold关联的编号，匿名补采后分别报告，不能挑较好的一版作为干净基线。

## 三种“三类”不是同一个任务

- 普通NLI：entailment／neutral／contradiction，蕴含有方向。
- 记忆动作：coexist／replace_all／merge_preserve，局部保留是任务的一部分。
- 原子关系：equivalent／compatible／conflict，单向包含归compatible；它不直接批准更新。

五叶集合关系可按方向投影到NLI，但不能无痛投影成动作三类。原子三类中的equivalent也不等于NLI entailment。因此后期公开迁移把原子预测折叠成**矛盾／非矛盾**，不伪造三类NLI准确率。任务不匹配与数据差异应明确分列，而不是用映射掩盖。

## 基准用途与曝光

OCNLI、ANLI、HANS、ContractNLI分别用于中文NLI、对抗NLI、词面启发式和合同条款关系诊断。长文本、缺gold、无共识、无可用证据跨度、截断与解析失败分别计数；HANS生成标签与人工参考也不是同种来源。

官方test没有公开gold时不能按错题或负例处理，也不能把它悄悄删掉后仍称“官方全量”。分区尽量按共享前提、同文语义对和来源簇连接，避免逐行随机切分把相关样本拆开。

旧终测看过后，只能叫已曝光诊断或回归集。原子化抽取、公开NLI和整套记忆事务各测不同问题，不能拿一项成绩替另一项背书。

## 统计与决策原则

1. 报告实际分子／分母和缺失，不仅是百分比。known-reference、confirmed/all-planned、completion是三个指标。
2. 同一批候选、同一参考、同一评估器才能作直接配对；更换参考导致的涨分先记作尺子变化。
3. 同更新数／实例呈现量不等于同token、同独立根数，也不等于两臂都达到各自最优收敛。
4. 分别报告全量与选择性子集、覆盖与条件错误；接近1的softmax不是已校准风险界。0个错误也需考虑样本量和独立性。
5. 按语义根／family／连通簇重采样，seed分报；固定两seed的条件区间不覆盖所有初始化不确定性。
6. 不在已经看过的终测上重新挑权重、阈值或seed。新的确认、旧表纠错和后验探索明确标注。
7. 在写判据前检查天花板：起点93.75%时不可能再涨10pp；保留原失败结果，同时解释判据为何不可达。
8. 同时看漏冲突、误等价、信息遗失和额外融合。macro-F1单项提高不等于业务策略全面改善。

## 公开副本与原档案的关系

公开清单同时登记原件与公开件SHA。没有敏感内容需要修改的数据，保留原字节；需要移除本机路径、凭据字段或隐藏推理的副本会标为transformed。模型参数提取为可核验张量，移除优化器／恢复状态不改变选中权重；公开转换本身不冒充新训练。

历史锁绑定原始路径和源码指纹时，不能在迁移后的公开目录中静默绕过，也不能拿新路径的哈希冒充原实验哈希。复算原始预测与建立新的复现实验锁分开。运行环境差异导致的数值误差应实测报告，不能承诺所有硬件上逐位一致。

公开包也附实际联合训练的canonical train/dev：`datasets/semantic-text/{early,tree}/`，每版分别118186／13202行，以及对应producer的转换记录。这些混合输入含ANLI、OCNLI、ContractNLI等第三方正文与自建代理文本，**并非全是原创、也不统一采用MIT**；ANLI与OCNLI的非商业条件继续适用。其它公开诊断可按所附来源配置从官方重取。源码、原预测、模型参数和数据共同构成复现材料；认证头、真实用户日志与内部代理事件流不属于公开研究数据。
